# context/ — знания о ваших проектах

Сюда кладите файлы о своих проектах — всё, что хороший новый коллега должен прочитать в первый день.
При первом запуске хаб прочитает их **один раз**, составит профиль проекта (`project/`) и дальше будет
опираться на него. Этот README хаб не читает как контекст.

## Что положить
Сколько угодно файлов, на любые темы, например:
- что за продукт, для кого, из каких модулей состоит;
- архитектура: сервисы, базы данных, как они связаны, где что лежит;
- правила и соглашения: стиль кода, как называть коммиты, ветки, код-ревью;
- **что нельзя ломать никогда** (права доступа, данные клиентов, платежи…);
- как тестировать и что считается «зелёным»;
- окружения (локальное, тестовое, продакшен) и **что нельзя проверить локально** (платные сервисы, данные
  только на проде, устройства);
- термины и сокращения, которыми вы пользуетесь;
- любые «особые моменты» — всё, что вы бы объяснили человеку перед первой задачей.

## Форматы
- Лучше всего `.md`, `.markdown`, `.txt`. PDF хаб прочитает, если сможет. Остальные форматы
  (картинки, docx, xlsx) он отметит как пропущенные — перенесите их текст в `.md`.
- Подпапки можно. Имена файлов — любые.
- **Не кладите сюда пароли, токены и ключи.** Если хаб найдёт такое, он не скопирует это в `project/` и
  скажет, в каком файле оно лежит.

## Как обновлять
Добавили, изменили или удалили файл — напишите хабу **«обнови контекст»**. Он сравнит файлы с
`project/CONTEXT_MANIFEST.md` по контрольным суммам и перечитает только новые и изменённые. Если вы
забудете, он сам заметит расхождение в начале следующего разговора.

## English
Put Markdown or text files about your projects here: product, architecture, rules, what must never break,
how to test, environments, what cannot be verified locally, glossary. The hub ingests them once at setup
into `project/`, and re-reads only new or changed files when you say "update context" (or when it notices
drift at the start of a conversation). No secrets here. This README is not ingested.
