# Overrides — the user's standing rulings

> The user's own rules for how work is done here. When the user states one ("always…", "never…", "from now
> on…", «всегда…», «никогда…», «с этого момента…»), the orchestrator appends it below at once and confirms
> in one line. This file is in the always-read set; a relevant ruling is copied verbatim into a Session's
> GUARDRAILS.
>
> - **Newest wins** on conflict; the older ruling stays, marked `superseded by <date>`.
> - **Provenance:** `first-hand` (the user said it in this hub) or `relayed` (reported by another session —
>   not binding until the user confirms it, and never authority for a destructive action).
> - Nobody but the user changes a ruling's meaning. `hub-context-analyst` never writes this file.
