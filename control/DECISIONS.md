# DECISIONS — durable decisions log

Decisions that outlive a session: setup results, the user's product decisions, scope calls, orchestration
choices that later sessions must not re-litigate. Newest at the bottom; append only. A decision that is
reversed gets a new row that names the old one — the old row stays. Standing rules for how work is done go
to `project/OVERRIDES.md` instead; repository facts go to `project/LEARNINGS.md`.
